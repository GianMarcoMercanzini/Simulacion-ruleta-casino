Simulación ruleta de casino
La simulación se realiza mediante la generación de números aleatorios en el rango de 0 a 36, distribuidos en N tiradas.
El estudio incluye la presentación de gráficos, el análisis de los resultados obtenidos, y el cálculo de diversas funciones
estadísticas como media, varianza, desvío estándar y frecuencia relativa. Los resultados se contrastan con los valores
teóricos esperados
